Что было сделано в рамках работы
Выявлена и исправлена логическая ошибка в бизнес‑логике.
В классе DiscountCalculator условие начисления скидки было некорректным: скидка не применялась для заказов ровно на 1000 рублей из‑за строгого сравнения total > Threshold. По требованиям («от 1000 включительно») условие заменили на total >= Threshold.

Покрыт код тестами и проверена корректность исправления.
Написано 24 тестовых метода (37 сценариев с параметризацией), включая проверку граничных значений (ровно 1000 рублей). Тесты подтвердили, что после правки скидка начисляется верно.

Проверено взаимодействие сервисов с помощью Moq.
С помощью библиотеки Moq изолированы зависимости:

проверка, что при ошибке сохранения заказа событие в репозиторий не публикуется (используется Times.Never);
проверка, что при ошибке публикации исключение пробрасывается наверх.
Настроен CI‑конвейер в GitHub Actions.
Создан файл .github/workflows/ci.yml, который автоматически:

проверяет код при каждом push в ветку main;
устанавливает нужную версию .NET;
восстанавливает зависимости, собирает проект и запускает тесты.
Подтверждена работоспособность CI.
На вкладке Actions видны успешные запуски workflow (зелёные галочки), что доказывает: сборка проходит, тесты выполняются, проект готов к непрерывной интеграции.

Ключевые метрики покрытия кода
Покрытие блоков — 90,1 %;
Покрытие строк — 89,6 %.
Это хороший показатель для учебного проекта: покрыты основные сценарии и граничные случаи, включая исправление ошибки.
